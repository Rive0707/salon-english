v1.0（2026-11-14）の内容：
SpeakFlowとは別のアプリです。サロンで使う接客英語を学ぶPWAです。
静的サイトのみ（バックエンド不要）で、RenderのStatic Siteとして無料で動きます。


- フレーズ：10シーン・40フレーズ（お出迎え、カウンセリング、シャンプー、
カット、カラー・パーマ、仕上げ、お会計・次回予約、商品提案、雑談、お困りのとき）
英語＋日本語訳、音声読み上げ（TTS）、★お気に入り保存
- ドリル：接客シーンの瞬間英作文。Geminiが問題を出して採点します。
キーがなくても練習問題10問で使えます。
キーはSpeakFlowと同じものを使えます（localStorageの speakflow_gemini_key を読む）。
- お気に入り：★をつけたフレーズの一覧


- index.html（アプリ本体）
- manifest.webmanifest / sw.js（PWA、キャッシュ salon-v1）
- icon-192.png / icon-512.png
- render.yaml（Render Static Site用）


1. GitHubに新しいリポジトリを作り、このフォルダの中身を全部アップロードする
2. Renderで「New Static Site」を作り、そのリポジトリを選ぶ
3. 公開URLをスマホで開き、Chromeメニュー「ホーム画面に追加」でインストール


- フレーズと問題文はすべてオリジナルです。他社の教材・LPの文章は使っていません。
- GeminiのAPIキーはスマホの中だけに保存されます。
